# Portfolio — rj.lackoff.com

My personal portfolio — a full-stack website showcasing my work as a Backend & Cloud Engineer.

🔗 **Live:** https://rj.lackoff.com

## Features
- Dynamic content served from a Node.js backend + MongoDB
- Responsive, animated UI

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Framer Motion, React Router
- **Backend:** Node.js, Express, MongoDB
- **Deployment:** self-hosted on Linux with Nginx reverse-proxy + SSL
